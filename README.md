# AI Chatbot

## Project Description
This is a simple AI Chatbot developed using Java. It interacts with users and provides responses to their messages.

## Features
- Accepts user input.
- Responds to user messages.
- Provides simple conversations.
- Easy to use.
- Displays responses in the console.

## Technologies Used
- Java
- Scanner
- Conditional Statements
- Loops
- String Handling

## How to Run
1. Download ChatBot.java.
2. Open the terminal or command prompt.
3. Compile using `javac ChatBot.java'
4. Run using `java ChatBot'
